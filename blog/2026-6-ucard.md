# 整理一下全网目前各种海外支付的卡

## 开卡流程

- 先要有币安或欧易（欧易这块我踩了个坑痛失 20 刀，注册成功后一定进去先领任务在 C2C充钱，不然很多新手任务就没有资格了），这块先领任务在充钱。
- 然后注册 Neverless，就可以给 Wise 入金了。
- 然后注册 Wise，100 刀小额入金（欧洲 比利时）激活。

## 海外U卡

> 我一直没有明白 Fiat24 和 Bitget 的关系，后来各种查询之后在明白，Fiat24 相当于海外的借记卡发行商，Bitget 是和 币安/OKX 一样的平台，Bitget 和 Fiat24 一起合作退出了一个万事达借记卡卡可以绑定微信、支付宝、Apple Pay 等，相当于是一个万事达借记卡。
>
> Bitget 和 SafePal 只能开一个
>
> 办卡前可以搜一下有没有什么邀请码之类的可以有手续费优惠

### Fiat24: Bitget Wallet【已办】

| 字段             | 说明                                          |
| ---------------- | --------------------------------------------- |
| **类型**         | 虚拟MasterCard(美国bin) + 加密货币钱包        |
| **办理渠道**     | https://linux.do/t/topic/1495502 BitgetWallet |
| **难度**         | 中等                                          |
| **办理条件**     | 护照+虚拟定位+香港地址（可选）                |
| **办理时间**     | 4 小时折腾                                    |
| **入金激活流程** | OKX --USDC-> Bitget Wallet                    |

> 这个卡是可以绑定 Apple Pay 去订阅 GPT 的，如果被封号可以有机会退回卡里，然后绑定支付宝和微信可以花出去。
>
> 注意：
>
> - 支付宝付款不要大于 200 每笔，大于 200 会收 3% 的手续费。
> - 每个月只有 400 刀是免手续费的。
> - 全程挂香港梯子，地址可以去闲鱼找私人信箱代收，虚拟定位是Fake GPS，我的设备是 Redmi k90 ProMax
> - 安卓 APP 名字是 `Bitget Wallet`
> - 注意要使用推荐码注册，只有这样才有 5刀 的消费奖励返现
>
> 相关教程：
>
> - https://linux.do/t/2361398
