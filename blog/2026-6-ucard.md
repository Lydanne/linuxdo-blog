# 整理一下全网目前各种海外支付的卡

## 国内

> 国内的最好办了，我就举了几个我了解过的。

### 招商visa 信用卡【贴主办过】

| 字段         | 说明              |
| ------------ | ----------------- |
| **卡类型**   | 信用卡            |
| **办理渠道** | 各大线下网点      |
| **难度**     | 简单              |
| **办理条件** | 身份证+国内手机号 |
| **办理时间** | 1 小时            |

> 我目前办的说是什么毕业生的卡完全免年费（就算是不消费），当时还送了一个空气炸锅呢。

### 招商万事达借记卡

| 字段         | 说明              |
| ------------ | ----------------- |
| **卡类型**   | 借记卡            |
| **办理渠道** | 各大线下网点      |
| **难度**     | 简单              |
| **办理条件** | 身份证+国内手机号 |
| **办理时间** | -                 |

> 因为我有一类招商卡了，办理需要销卡，但是这个卡绑定了一些东西就没销，所以就没办办了一个兴业银行的寰宇人生的普卡。
>
> 这个卡是有两种类型的普卡和金葵花，注意外汇功能只有 I 类卡才能办：
>
> - 1 是普卡
>   - 免管理费
>   - 境外 ATM 取款每月首笔免手续费，后面每笔收 1% 最低 10 人民币或者 2 美元
>   - 其他不太清楚
>
> - 2 是金葵花卡
>   - 2026 年 12 月 31 日前免管理费，之后是小于 50w 每个月 150 管理费
>   - 境外 ATM 取款每月前 3 笔免手续费，后面每笔收 1% 最低 10 人民币或者 2 美元
>   - 其他不太清楚

## 海外

> 我一直没有明白 Fiat24 和 Bitget 的关系，后来各种查询之后在明白，Fiat24 相当于海外的借记卡发行商，Bitget 是和 币安/OKX 一样的平台，Bitget 和 Fiat24 一起合作退出了一个万事达借记卡卡可以绑定微信、支付宝、Apple Pay 等，相当于是一个万事达借记卡。
>
> Bitget 和 SafePal 只能开一个
>
> 办卡前可以搜一下有没有什么邀请码之类的可以有手续费优惠

### Fiat24: Bitget【贴主办过】

| 字段         | 说明                                          |
| ------------ | --------------------------------------------- |
| **卡类型**   | 借记卡                                        |
| **办理渠道** | https://linux.do/t/topic/1495502 BitgetWallet |
| **难度**     | 中等                                          |
| **办理条件** | 护照+虚拟定位                                 |
| **办理时间** | 护照 10 天+2 小时折腾                         |

> 这个卡是可以绑定 Apple Pay 去订阅 GPT 的，如果被封号可以有机会退回卡里，然后绑定支付宝和微信可以花出去。
>
> 注意：
>
> - 支付宝付款不要大于 300 每笔，大于 300 会收 3% 的手续费。
>
> 相关教程：
>
> - https://linux.do/t/2361398
