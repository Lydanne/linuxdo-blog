# 1000 美元跨境电汇流程和费用总结

日期：2026-06-13

本文按两个方向说明：

- 从中国向境外转出 1000 美元
- 境外向中国转回 1000 美元

金额和汇率仅为估算，实际以办理当天银行牌价、收付款银行规则、SWIFT 路径和费用承担方式为准。

## 一、从中国向境外转出 1000 美元

如果你手里是人民币，要给境外账户转 1000 美元，通常流程是：

1. 购汇：人民币换成美元。
2. 境外电汇：通过 SWIFT 把美元汇到境外账户。
3. 境外收款银行入账：收款银行或中间银行可能扣费。

### 1. 购汇

购汇就是用人民币买美元。

个人年度便利化额度通常是每人每年等值 5 万美元。1000 美元在额度内，一般凭身份证和真实用途申报即可办理。

假设汇率约为：

```text
1 USD = 6.76-6.77 RMB
```

那么购汇 1000 美元本金大约需要：

```text
1000 x 6.76-6.77 = 6760-6770 元人民币
```

实际成交价通常看银行的美元“现汇卖出价”，不是中间价。

### 2. 中国端电汇费用

以中国银行个人电子银行跨境电汇费率为例：

- 手续费：汇款金额的 1‰，最低 50 元，最高 260 元
- 非港澳台地区电讯费：150 元

1000 美元的 1‰约为 1 美元，折合人民币约 6-7 元，低于最低收费，所以按最低 50 元收。

中国端费用粗算：

| 项目 | 金额 |
|---|---:|
| 电汇手续费 | 50 元人民币 |
| 电讯费 | 150 元人民币 |
| 合计 | 200 元人民币 |

### 3. 你大约需要准备多少钱

| 项目 | 粗算金额 |
|---|---:|
| 购汇本金 | 6760-6770 元人民币 |
| 中国端电汇费用 | 200 元人民币 |
| 中国端合计支出 | 6960-6970 元人民币左右 |

注意：这只是中国端支出。境外收款银行、中间银行可能还会从 1000 美元本金中扣费。

### 4. 境外到账金额

境外实际到账取决于：

- 境外收款银行是否收 incoming wire fee
- 是否经过中间银行
- 费用承担方式是 OUR、SHA 还是 BEN

常见估算：

| 情况 | 收款人可能到账 |
|---|---:|
| 费用由汇款人承担，路径顺畅 | 接近 1000 美元 |
| 中间银行或收款银行扣费 | 约 970-990 美元 |
| 多家银行扣费或选择 BEN | 可能低于 970 美元 |

## 二、境外向中国转回 1000 美元

如果境外给你往中国账户转 1000 美元，流程反过来：

1. 境外汇款人发起 SWIFT 电汇。
2. 中间银行可能参与清算并扣费。
3. 中国收款银行把美元入到你的外币账户。
4. 你决定是否结汇成人民币。

这时你不是购汇，而是收汇。只有你把收到的美元换成人民币时，才叫结汇。

### 1. 境外汇出端

境外汇款人需要填写：

- 你的英文姓名
- 你的中国银行账号
- 中国收款银行名称和地址
- 中国收款银行 SWIFT/BIC
- 汇款用途
- 如银行要求，还要填写中间行或汇路指引

境外银行通常会向汇款人收汇出手续费。这个费用由境外银行决定，可能是几十美元。

### 2. 中间银行

中间银行也叫中转行、代理行、intermediary bank 或 correspondent bank。

它的作用是：如果境外汇出银行和你的中国收款银行之间没有直接清算关系，钱会经过一家或多家中间银行，再到你的中国银行账户。

典型路径：

```text
境外汇出银行 -> 中间银行/美元清算银行 -> 中国收款银行 -> 你的账户
```

中间银行通常由以下方式决定：

| 方式 | 谁决定 | 特点 |
|---|---|---|
| 不指定中间行 | 境外汇出银行自动选择 | 最常见，但扣费不透明 |
| 按中国收款银行的汇路指引填写 | 你向中国银行索取后给汇款人 | 推荐，路径更明确 |
| 使用同集团银行 | 例如境外中行到中国中行 | 可能更顺畅，但要看当地支持 |
| 使用非 SWIFT 平台 | Wise、Remitly 等 | 费用可能更透明，但不是传统银行电汇 |

### 3. 中间银行怎么收费

中间银行费用没有统一标准，常见是每家 10-30 美元左右。可能不扣，也可能经过多家银行被扣多次。

这笔费用通常不是你在中国柜台支付，而是在汇款途中直接从本金中扣。

例如境外给你汇 1000 美元：

| 情况 | 你可能收到 |
|---|---:|
| 没有中间扣费，或汇款人承担费用 | 接近 1000 美元 |
| 中间行扣 10 美元 | 990 美元左右 |
| 中间行扣 20-30 美元 | 970-980 美元左右 |
| 多家银行扣费 | 可能低于 970 美元 |

### 4. OUR、SHA、BEN 的区别

这是 SWIFT 汇款里的费用承担方式。

| 方式 | 含义 | 对到账金额的影响 |
|---|---|---|
| OUR | 汇款人承担费用 | 你更可能收到接近 1000 美元 |
| SHA | 双方分担费用 | 境外汇出费由对方付，中间行或收款端可能从本金扣 |
| BEN | 收款人承担费用 | 所有费用尽量从本金扣，你到账最容易少 |

如果你希望尽量完整收到 1000 美元，建议让对方选择 OUR，并按你的中国收款银行提供的美元汇入汇款路径填写。

### 5. 到账后是否结汇

如果你的中国账户支持美元外币账户，1000 美元汇入后通常先以美元现汇入账。

你有两个选择：

#### 选择 A：不结汇

账户里继续持有美元现汇。以后可以再汇出、消费、或等汇率合适时再结汇。

#### 选择 B：结汇成人民币

结汇就是把美元卖给银行，换成人民币。

结汇时银行通常按美元“现汇买入价”给你人民币。这个价格一般低于你购汇时用的“现汇卖出价”，差额就是银行汇率价差。

粗算：

```text
如果到账 1000 美元，按 6.75 结汇：
1000 x 6.75 = 6750 元人民币
```

如果中间银行扣了 20 美元，只到账 980 美元：

```text
980 x 6.75 = 6615 元人民币
```

## 三、购汇和结汇的区别

| 名称 | 方向 | 例子 |
|---|---|---|
| 购汇 | 人民币换美元 | 你从中国往外汇 1000 美元前，用人民币买美元 |
| 结汇 | 美元换人民币 | 境外给你汇回 1000 美元后，你把美元换成人民币 |

从中国向境外付款：通常是购汇 + 电汇。

境外向中国汇款：通常是收汇 + 可选结汇。

不要把两者混在一起。如果你已经有美元并要汇出，一般不需要先结汇再购汇，否则会多损失一次汇率价差。

## 四、实际操作建议

### 你从中国向境外转 1000 美元

1. 确认收款人英文姓名、地址、账号。
2. 确认收款银行英文名称、地址、SWIFT/BIC。
3. 如美国收款银行要求，确认 ABA routing number。
4. 在中国银行办理购汇。
5. 发起跨境电汇。
6. 选择费用承担方式。若希望对方尽量完整收到，优先考虑 OUR，但费用可能更高。
7. 保存电汇回单。

### 境外给你往中国转 1000 美元

1. 先向你的中国收款银行索取美元汇入汇款路径或汇路指引。
2. 把你的英文姓名、账号、银行 SWIFT/BIC、银行地址、汇路指引发给对方。
3. 告诉对方如果希望你完整收到 1000 美元，选择 OUR。
4. 让对方汇出后提供 SWIFT MT103 回单。
5. 到账后确认收到的是多少美元。
6. 决定是否结汇成人民币。

## 五、核心结论

- 从中国向境外转 1000 美元：你主要承担购汇本金和中国端电汇费。按示例粗算，中国端约需 6960-6970 元人民币。
- 境外向中国转回 1000 美元：你主要关注中间银行扣费和到账后是否结汇。
- 中间银行费用通常不透明，常见每家 10-30 美元，可能没有，也可能扣多次。
- 想减少扣费和出错，最重要的是使用中国收款银行提供的汇路指引，并让汇款人尽量选择 OUR。
- 最终金额以实际银行汇率、SWIFT 路径和费用承担方式为准。
